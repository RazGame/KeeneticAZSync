# Повторная проверка безопасности — 12 ноября 2026

Проверены текущий код AWG Sync, публичный конвертер, HTTP-политика доступа, входящие конфигурации, работа с секретами, зависимости npm и установленный Docker-образ. Проверки на рабочей установке ограничивались чтением и небольшим числом HTTP-запросов: клиенты не создавались, VPN не переключались, нагрузочные атаки не запускались.

## Найденные проблемы и исправления

| Проблема | Условия и последствия | Исправление |
| --- | --- | --- |
| Обход лимита проверки паролей, средний риск | `/api/session` проверял Basic credentials без учёта неудачных попыток. На других маршрутах пароль сравнивался до проверки лимита: верная догадка оставалась отличима после `429`. Это позволяло продолжать подбор; само по себе не давало вход без пароля. | Все явно переданные credentials используют общий бюджет. После 20 ошибок за минуту запрос блокируется до сравнения пароля; `429` содержит `Retry-After`. Анонимная проверка наличия сессии и действующие cookies продолжают работать. |
| Внедрение команды в `routes.bat`, высокий риск при импорте вредоносного файла и запуске результата | Поля `Address` и `AllowedIPs` попадали в batch-команды без проверки IP. В локальной проверке строка с безвредным маркером `&echo AUDIT_MARKER` дошла до скачиваемого файла. Batch-файл не запускался. | Генерация принимает только IPv4/CIDR с корректными октетами и префиксом. Метасимволы, неверные IP и неоднозначные ведущие нули отклоняются. Скриптовые хуки `PreUp/PostUp/PreDown/PostDown` запрещены. ASC проверяется до публикации результата; недопустимый профиль не включает скачивание. |
| Устаревший системный пакет `zlib` | Официальная база Alpine 3.24 отметила установленный `zlib 1.3.2-r1` по CVE-2026-4738; исправление указано в `1.4-r0`. Это совпадение по пакету, а не подтверждённая эксплуатация в AWG Sync. | При сборке выполняется обновление пакетов Alpine; опубликованный образ перед установкой проверяется повторно. Node использует собственную сборку zlib и не линкуется с системной libz; обновление apk не означает замену встроенной библиотеки Node. |

## Что проверено

- Без авторизации `/api/config`, `/api/export`, `/api/mappings` возвращают `401`. Пути к `.env`, YAML и попытки выхода из каталога статических файлов возвращают `404`.
- Публичная `/converter` возвращает только статический интерфейс. CSP содержит `connect-src 'none'`, `form-action 'none'`, запрет объектов и встраивания. Исходные файлы не отправляются на сервер.
- Проверены проверки Origin, сессии, отзыв cookie, маскирование паролей, ограничения JSON/YAML и атомарное сохранение, привязка cookies устройств к origin, ограничения HTTP-ответов и времени операций, подтверждение плана перед записью.
- Рабочий контейнер: пользователь `node`, read-only rootfs, `cap_drop ALL`, `no-new-privileges`, без privileged и без опубликованного напрямую порта Node. Каталог конфигурации — `0700`, файл — `0600`, UID/GID 1000.
- Установленный Node — `24.22.3`, security release от 11 ноября 2026. Это не доказывает отсутствия будущих уязвимостей.
- `npm audit --omit=dev`: 0 известных уязвимостей. До исправлений ОС проверены 19 установленных пакетов по 160 записям исправлений Alpine; найдено указанное выше совпадение zlib.
- 139 автоматических тестов прошли локально, включая подбор через session endpoint, блокировку до сравнения верного пароля, сохранение доступа действующей сессии, внедрение в batch и восстановление после отклонённого файла. Проверки не требуют доступа к реальным устройствам.

## Границы результата

Не обнаружен обход авторизации к административным данным или подтверждённое удалённое выполнение команд на сервере. Это ограниченный аудит кода и конфигурации, а не гарантия отсутствия уязвимостей. Отдельный полный пентест прошивок роутеров, VPN-панелей, Caddy и хоста не выполнялся.

AWG Sync рассчитан на одного доверенного администратора: нет MFA и ролей. Он может обращаться к внутренним адресам и менять устройства. Пароли устройств остаются в приватном YAML, незашифрованный экспорт содержит секреты. Явные исключения проверки TLS продолжают действовать для тех подключений, где их настроил владелец.
