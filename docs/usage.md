# Как пользоваться AWG Sync

[← На главную](../README.md)

Если вы только что запустили приложение, начните с [первой настройки](../README.md#первая-настройка). Ниже — ответы на вопросы о разделах и действиях.

## Что означают названия

| Название | Простое объяснение |
| --- | --- |
| Сервер | Машина, на которой работает ваш VPN. |
| Панель | Веб-интерфейс управления VPN-клиентами: WG-Easy или OpenVPN UI. |
| Клиент | Отдельный VPN-профиль в панели. Обычно для каждого роутера создают свой. |
| Интерфейс роутера | VPN-подключение в настройках самого роутера. |
| Маппинг | Сохранённая связь между клиентом на сервере и интерфейсом роутера. |

## Добавить или изменить доступы

1. Откройте **«Доступы»**.
2. Выберите **«Серверы»** или **«Роутеры»**.
3. Откройте нужную карточку или добавьте новую.
4. Заполните адрес, логин и пароль. У сервера доступы к каждой панели задаются отдельно.
5. Нажмите общую кнопку **«Сохранить»**.

Сохранение этих полей запоминает доступы в приложении. Для изменения VPN на роутере нужно отдельно проверить и применить настройки.

Чтобы поменять порядок карточек, нажмите **«Изменить порядок»**, переставьте элементы стрелками и сохраните. Этот порядок будет использоваться во всех разделах.

## Создать подключение

1. Откройте **«Маппинги»** и нажмите **«+ Подключение»**.
2. Выберите роутер, сервер и тип VPN.
3. Выберите клиента панели или создайте нового.
4. Выберите существующий интерфейс роутера или создание нового.
5. На последнем шаге изучите, какие настройки изменятся.
6. Примените изменения сейчас или нажмите **«Применить позже»**.

**Клиент, созданный в мастере, уже существует на сервере.** А создание или изменение интерфейса роутера выполняется только при применении. Поэтому после «Применить позже» связь появится в приложении, но настраивать роутер вы будете позже.

Новый интерфейс после применения включается. Для существующего интерфейса использование выбирается отдельно. Перед включением выбранного VPN приложение отключает остальные VPN этого роутера, которые добавлены в маппинги. При ошибке оно попытается восстановить прежнее подключение и сообщит результат.

Удаление маппинга убирает связь из приложения. Клиент в панели и интерфейс роутера остаются.

## Проверить и применить настройки

1. Откройте **«Синхронизация»**.
2. Если хотите обработать только часть подключений, отметьте их галочками. Без отметок проверяются все связи с включённой синхронизацией.
3. Нажмите кнопку проверки.
4. Раскройте подключения, где найдены изменения, и посмотрите план.
5. Нажмите **«Применить изменения»** и подтвердите нужные подключения.

Если настройки уже совпадают, применять ничего не требуется. После изменения параметров проверки выполните её снова.

Проверка и применение идут параллельно максимум на трёх роутерах. Подключения одного роутера обрабатываются последовательно. Пока выбранные устройства заняты, можно выбрать свободный роутер и запустить для него другую задачу. Роутеры с выполняющимся или ожидающим тестом iperf временно пропускаются.

В карточке есть два независимых состояния:

| Состояние | На какой вопрос отвечает |
| --- | --- |
| VPN на роутере | Подключён ли VPN сейчас? |
| Настройки | Совпадают ли настройки роутера с конфигурацией из панели? |

Например, VPN может быть выключен, а его настройки — полностью совпадать.

Статус VPN обновляется раз в 15 секунд, пока открыт и виден раздел «Синхронизация». После переключения через панель первые 30 секунд проверяем соединение чаще — раз в 2 секунды, пока оно не подключится. При уходе в другой раздел или скрытии вкладки опрос прекращается. Планы изменений и отмеченные подключения при обновлении статуса сохраняются.

### Как переключить VPN

Раскройте нужное подключение и нажмите **«Использовать это подключение»**. В подтверждении проверьте, что будет включено и какие другие VPN отключатся.

Простая проверка настроек VPN не переключает.

### Что делает флаг «Синхронизация включена»

Он определяет, участвует ли связь в общей синхронизации и мониторинге. Это **не кнопка подключения VPN**. Если выключить этот флаг, состояние самого VPN на роутере не изменится.

## Использовать домен вместо IP

1. Откройте сервер в разделе **«Доступы»**.
2. Заполните **«Доменное имя»**, например `vpn.example.com`.
3. Включите **«Использовать доменное имя в конфигурации»**.
4. Сохраните доступы.
5. Проверьте и примените соответствующие подключения в **«Синхронизации»**.

После применения роутер будет подключаться к этому домену. Порты сохранятся. Адреса административных панелей от этой настройки не меняются.

Если флаг выключен, используется адрес, записанный в VPN-конфигурации самой панели.

## Посмотреть текущий трафик

Откройте **«Мониторинг»**. На карточках показаны:

- **Скачивание** — данные, поступающие к роутеру через VPN.
- **Отдача** — данные, которые роутер отправляет через VPN.

Это текущий трафик. Если никто ничего не скачивает, низкие значения или ноль — нормальны. Для измерения доступной скорости используйте тест iperf3 ниже.

В поле **«Источник»** можно выбрать:

| Источник | Как работает |
| --- | --- |
| **Сервер**, выбран по умолчанию | Считывает данные клиентов из VPN-панелей. Ради графиков роутер регулярно не опрашивается. |
| **Роутер** | Считывает данные активного VPN непосредственно с роутера и проверяет его состояние при каждом замере. |

При источнике «Сервер» используется подключение из последней известной проверки роутера. Если переключили VPN вне AWG Sync, нажмите **«Обновить подключения»**. Эта кнопка один раз перечитает состояние роутера. Время проверки видно в карточке.

Данные обновляются примерно раз в 10 секунд после ответа. Уйдите из раздела, скройте вкладку или нажмите **«Пауза»**, и новые запросы прекратятся. Уже начатый запрос может завершиться, но постоянного фонового сбора нет.

График хранит до 10 минут наблюдений и переживает обновление текущей вкладки. При выходе из аккаунта история очищается. После перерыва на графике будет разрыв: приложение не придумывает значения за время, когда вы его не наблюдали. При переключении источника истории не смешиваются.

<details>
<summary>Почему данные сервера могут отличаться от данных роутера</summary>

Сервер видит обмен VPN-клиента, а роутер — своё VPN-подключение. Если один клиент используется на нескольких устройствах, серверные счётчики покажут их общий трафик. Для точной привязки создавайте отдельного клиента для каждого роутера.

Если состояние роутера ещё не проверено или проверить его не удалось, приложение ориентируется на текущую OpenVPN-сессию или недавний обмен WireGuard. Это помогает найти вероятное подключение, но не доказывает, что оно выбрано активным на роутере. При необходимости обновите подключения вручную.

Учитываются только связи с включённой синхронизацией. Если у роутера таких связей нет, его карточка в мониторинге не показывается.

</details>

## Измерить скорость VPN

1. В **«Синхронизации»** раскройте активное подключение.
2. Откройте **«Тест скорости · iperf3»**.
3. Выберите сервер AntiZapret: `az-local.antizapret` или `az-world.antizapret`.
4. Оставьте скачивание, если хотите проверить скорость **с сервера до роутера**, либо выберите отдачу.
5. Запустите тест и дождитесь результата.

По умолчанию тест использует **10 потоков на 10 секунд**. Общая операция может длиться дольше из-за подготовки и завершения на роутере. Приложение покажет скорость отправляющей и принимающей сторон, объём данных и журнал теста.

Рядом с результатом указаны дата и время запуска и завершения в часовом поясе вашего браузера. Если после открытия панели показан старый результат, дата относится к тому замеру: открытие страницы не запускает новый тест.

На роутере должен быть установлен компонент iperf3, а выбранный VPN должен работать. Если компонента нет или сервер недоступен, появится ошибка. Приложение не переключает VPN ради теста автоматически.

До трёх тестов к разным серверам могут выполняться одновременно. Тесты к одному серверу автоматически идут по очереди: в карточке видно ожидание и место в очереди. Цели `az-local` и `az-world` одного сервера используют общую очередь, поскольку могут вести в один контейнер AZ. Отменить можно и работающий тест, и ещё не запущенный. После обновления страницы состояния и результаты восстановятся; перезапуск самой AWG Sync очищает их.

Пока тест выполняется или ждёт запуска, настройки этого роутера защищены от изменения. Другими роутерами можно пользоваться. Ожидание в очереди ограничено пятью минутами; если время истечёт, появится ошибка и тест не запустится.

[Подготовка сервера iperf в AntiZapret](https://github.com/xtrime-ru/antizapret-vpn-docker#test-speed-with-iperf3). Сервер должен быть доступен с роутера через выбранный VPN на TCP-порту 5201.

## Сохранить и восстановить резервную копию

**Чтобы сохранить:** откройте **«Конфигурация»**, выберите зашифрованную копию, придумайте пароль и скачайте файл. Храните пароль отдельно — он понадобится для восстановления.

**Чтобы восстановить:** в том же разделе выберите файл, введите пароль и подтвердите замену настроек приложения.

Копия переносит доступы и связи между установками AWG Sync. Настройки на самих роутерах меняются отдельно, через синхронизацию.

Обычный YAML-экспорт содержит пароли открытым текстом. Используйте его только там, где это действительно нужно, и не публикуйте.

## Подготовить конфигурацию вручную

В **«Конвертере»** выберите файл `.conf` AmneziaWG. В результатах появятся обновлённый `.conf`, `routes.bat` и команда ASC, если исходный файл содержит нужные параметры.

Обработка выполняется в браузере; исходный профиль на сервер не отправляется.

<details>
<summary>Командная строка для автоматизации</summary>

Команды выполняются из папки `node`. Посмотреть план для всех включённых связей:

```bash
node bin/awgsync.js --all
```

Посмотреть одну связь по её техническому имени:

```bash
node bin/awgsync.js home-eu-awg
```

Применить изменения для всех включённых связей:

```bash
node bin/awgsync.js --all --apply
```

Без `--apply` программа только читает данные и показывает план. Явно указанное имя позволяет выбрать конкретную связь, в том числе выключенную для общей синхронизации.

| Параметр | Назначение |
| --- | --- |
| `--config PATH` | Использовать указанный файл настроек. |
| `--with-secrets` | Обновлять ключи и при необходимости пересоздавать VPN-пир. |
| `--no-restart` | Не перезапускать активное соединение после изменения. |
| `--help` | Показать справку. |

Не запускайте запись из командной строки одновременно с другим процессом, управляющим теми же роутерами.

</details>
