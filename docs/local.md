# Запуск на своём компьютере

[← На главную](../README.md)

Этот способ подходит, если вы хотите открыть AWG Sync на компьютере и управлять своими роутерами. Когда компьютер или приложение выключены, сама админка недоступна. Уже настроенные VPN на роутерах продолжают работать.

**Самый простой путь — обычный запуск через Node.js.** Docker нужен только в том случае, если вы уже им пользуетесь или хотите держать приложение в контейнере.

## Обычный запуск: Windows, Linux и macOS

### Шаг 1. Установите Node.js

Скачайте [Node.js 24](https://nodejs.org/) и установите его. После установки откройте новое окно терминала и проверьте:

```bash
node --version
npm --version
```

Обе команды должны показать номер версии. У Node.js он должен начинаться с `v24.`. Если команда не найдена, перезапустите терминал; в Windows иногда нужен перезапуск компьютера.

### Шаг 2. Скачайте проект

Откройте [репозиторий проекта](https://github.com/RazGame/KeeneticAZSync), нажмите **Code → Download ZIP** и распакуйте архив в удобную папку.

Откройте терминал в распакованной папке — той, в которой лежат `README.md` и папка `node`. В Windows для этого можно нажать правой кнопкой по папке и выбрать **«Открыть в терминале»**.

Если вместо ZIP хотите использовать Git, выполните:

```bash
git clone https://github.com/RazGame/KeeneticAZSync.git awg-sync
cd awg-sync
```

### Шаг 3. Установите библиотеки и запустите приложение

```bash
cd node
npm ci
npm run gui
```

Дождитесь сообщения об адресе панели. **Оставьте это окно терминала открытым** — в нём работает приложение.

### Шаг 4. Откройте панель

Перейдите в браузере на **http://127.0.0.1:8787**. Этот адрес означает «на текущем компьютере».

При первом запуске вход без пароля разрешён только с этого компьютера. Настройки пока пустые; заполните их по разделу [«Первая настройка»](../README.md#первая-настройка).

Чтобы остановить приложение, вернитесь в терминал и нажмите **Ctrl+C**. В следующий раз достаточно открыть терминал в папке `node` и выполнить `npm run gui`.

<details>
<summary>Если порт 8787 занят</summary>

Остановите предыдущий экземпляр или запустите приложение на другом порту:

```bash
node bin/awgsync.js serve 9000
```

В этом случае открывайте **http://127.0.0.1:9000**.

</details>

<details>
<summary>Как включить пароль даже при локальном запуске</summary>

Выполните команды в папке `node`. Пароль задаётся для входа в саму AWG Sync; доступы к роутерам вводятся отдельно в интерфейсе.

Windows, PowerShell:

```powershell
$env:BASIC_AUTH_USER = 'admin'
$env:BASIC_AUTH_PASS = Read-Host 'Придумайте пароль входа в AWG Sync'
npm run gui
```

Linux / macOS, Bash:

```bash
export BASIC_AUTH_USER=admin
read -rsp 'Придумайте пароль входа в AWG Sync: ' BASIC_AUTH_PASS
export BASIC_AUTH_PASS
printf '\n'
npm run gui
```

Пароль действует в этом окне терминала. После остановки закройте окно, чтобы убрать его из окружения. Файл `.env` при обычном запуске Node.js автоматически не читается.

</details>

## Docker

### Шаг 1. Подготовьте Docker и папку проекта

На Windows и macOS запустите Docker Desktop. На Linux нужны работающий Docker Engine и Compose v2.

Скачайте и распакуйте проект. Откройте терминал **в его корневой папке**, где лежит `docker-compose.yml`. В папку `node` для этого способа переходить не нужно.

### Шаг 2. Задайте логин и пароль

Сделайте копию файла с примером настроек.

Windows, PowerShell:

```powershell
Copy-Item .env.example .env
```

Linux / macOS:

```bash
cp .env.example .env
```

Откройте получившийся `.env` любым текстовым редактором. Заполните две строки:

```dotenv
BASIC_AUTH_USER=admin
BASIC_AUTH_PASS='ПРИДУМАЙТЕ_СВОЙ_ПАРОЛЬ'
```

Вместо `ПРИДУМАЙТЕ_СВОЙ_ПАРОЛЬ` введите собственный длинный пароль. Одинарные кавычки можно оставить: они позволяют использовать в пароле символ `$`. Строка `AWG_SYNC_DOMAIN` для локального запуска не нужна — её можно оставить как есть.

Если `.env` уже существует от предыдущего запуска, отредактируйте его, а не заменяйте примером.

### Шаг 3. Создайте папку настроек

Windows, PowerShell:

```powershell
New-Item -ItemType Directory -Force config
```

macOS с Docker Desktop:

```bash
mkdir -p config
```

Linux:

```bash
sudo install -d -m 700 -o 1000 -g 1000 config
chmod 600 .env
```

Linux-команда даёт приложению право сохранять настройки в этой папке. На Windows и macOS это обеспечивает Docker Desktop.

### Шаг 4. Запустите приложение

```bash
docker compose config --quiet
docker compose up -d --build
docker compose ps
```

Первая команда проверяет настройки: при успехе она ничего не выводит. Вторая собирает и запускает приложение; при первом запуске это может занять несколько минут. Третья показывает его состояние — после запуска должен появиться статус `healthy`.

Откройте **http://127.0.0.1:8787** и войдите с логином и паролем из `.env`. Затем перейдите к [первой настройке](../README.md#первая-настройка).

Терминал теперь можно закрыть: Docker продолжит работу в фоне, пока работает сам Docker.

### Как остановить и снова запустить

Из корневой папки проекта:

```bash
docker compose stop awg-sync
```

Повторный запуск:

```bash
docker compose up -d awg-sync
```

<details>
<summary>Панель открылась, но не видит роутер или VPN-сервер</summary>

Адрес должен быть доступен из контейнера. Указывайте LAN-адрес роутера или его облачный URL. `localhost` внутри контейнера указывает на сам контейнер.

Если нужная панель работает на том же компьютере, в Docker Desktop обычно подходит адрес `host.docker.internal` с её портом. На Linux способ доступа к хосту зависит от настройки сети Docker.

</details>

## Как обновить приложение

Сначала скачайте зашифрованную копию через **«Конфигурация»**. Свой `config.yaml` и `.env` сохраняйте: в них находятся доступы и связи.

Если проект скачан через Git, выполните `git pull --ff-only` из корневой папки. Если через ZIP — остановите приложение и перенесите файлы новой версии в ту же папку, сохранив свои файлы настроек.

При обычном запуске откройте папку `node`:

```bash
npm ci
npm run gui
```

При использовании Docker выполните из корня проекта:

```bash
docker compose up -d --build --no-deps awg-sync
```

После обновления войдите в панель заново. Уже существующих клиентов и интерфейсы пересоздавать не нужно.

## Если что-то не получилось

| Что вы видите | Что сделать |
| --- | --- |
| `node` или `npm` не найдены | Установите Node.js 24 и откройте новый терминал. |
| PowerShell запрещает запуск `npm.ps1` | Используйте `npm.cmd ci` и `npm.cmd run gui`. |
| Порт занят, `EADDRINUSE` | Остановите старый экземпляр или выберите порт 9000, как описано выше. |
| `EACCES`, настройки не сохраняются | Для Linux проверьте команду создания папки `config` на шаге 3. |
| Ошибка сертификата панели или роутера | Проверьте адрес и сертификат. Для собственного самоподписанного сертификата есть отдельное разрешение в дополнительных настройках подключения. |
| После обновления просят войти снова | Это ожидаемо: при перезапуске приложения сеансы входа сбрасываются. |

Показать последние сообщения Docker можно командой `docker compose logs --tail=100 awg-sync`. Перед публикацией сообщений удалите из них личные данные.

Для доступа с других устройств используйте [установку на сервере с HTTPS](server.md).
