# Приложение AWG Sync

Если вы уже открыли терминал в этой папке, запустите:

```bash
npm ci
npm run gui
```

Первая команда устанавливает библиотеки, вторая запускает панель. Откройте **http://127.0.0.1:8787** в браузере и оставьте терминал открытым. Для остановки нажмите **Ctrl+C**.

Нужен Node.js 24. Файл настроек создастся автоматически; серверы и роутеры добавляются через интерфейс.

| Что хотите сделать | Куда перейти |
| --- | --- |
| Установить на компьютер с нуля | [Локальный запуск](../docs/local.md) |
| Запустить на отдельном сервере | [Установка на сервер](../docs/server.md) |
| Добавить к работающему AntiZapret | [Инструкция для AZ](../docs/antizapret.md) |
| Настроить первое подключение | [Первая настройка](../README.md#первая-настройка) |
| Разобраться в кнопках и разделах | [Руководство](../docs/usage.md) |
| Найти файл настроек | [Конфигурация](../docs/configuration.md) |

Для запуска через Docker вернитесь в корневую папку проекта: там находится `docker-compose.yml`.

Для разработки доступна команда `npm test`. Тесты не обращаются к реальным устройствам. [Обзор проекта](../README.md) · [Безопасность](../SECURITY.md).
