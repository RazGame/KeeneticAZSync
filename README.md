# AWG Sync для Keenetic и Netcraze

AWG Sync помогает настроить VPN на роутере и поддерживать его настройки в актуальном состоянии. Приложение забирает конфигурацию из WG-Easy / AmneziaWG или OpenVPN UI, сравнивает её с настройками роутера и показывает, что нужно изменить. Вы сами решаете, когда применить изменения.

Всё основное можно сделать через браузер: добавить сервер и роутер, создать подключение, переключить VPN и посмотреть скорость.

## Быстро попробовать на компьютере

1. Установите [Node.js 24](https://nodejs.org/).
2. Откройте [репозиторий проекта](https://github.com/RazGame/KeeneticAZSync), нажмите **Code → Download ZIP** и распакуйте архив.
3. Откройте терминал в распакованной папке. В Windows можно нажать правой кнопкой по папке и выбрать **«Открыть в терминале»**.
4. Выполните команды по очереди:

```bash
cd node
npm ci
npm run gui
```

`npm ci` устанавливает необходимые библиотеки. `npm run gui` запускает приложение.

Откройте **http://127.0.0.1:8787** в браузере на этом же компьютере. Пока приложение нужно, оставляйте терминал открытым. Для остановки нажмите **Ctrl+C**.

Файл настроек создастся автоматически. На первом запуске он пустой — доступы вы добавите через интерфейс.

## Первая настройка

### 1. Добавьте VPN-сервер

Откройте **«Доступы» → «Серверы»**. Добавьте сервер, затем укажите адрес его панели WG-Easy или OpenVPN UI, логин и пароль.

Например, если вы открываете WG-Easy по адресу `https://vpn.example.com:5443`, введите этот же адрес в настройки подключения к панели.

### 2. Добавьте роутер

Перейдите в **«Доступы» → «Роутеры»**. Укажите адрес управления роутером и учётные данные для входа. Сохраните настройки.

**Адрес должен быть доступен с того устройства, где запущен AWG Sync.** При запуске дома обычно подходит LAN-адрес вроде `http://192.168.1.1`. При запуске на VPS обычно нужен облачный адрес KeenDNS / CrazeDNS или своя управляющая сеть.

### 3. Создайте подключение

В **«Маппингах»** нажмите **«+ Подключение»** и пройдите мастер. Он свяжет VPN-клиента на сервере с VPN-интерфейсом роутера. Можно выбрать уже существующие элементы или создать новые.

На последнем шаге изучите предложенные изменения и примените их. **«Применить позже»** сохранит связь, чтобы вернуться к ней затем.

### 4. Проверяйте настройки по мере необходимости

В **«Синхронизации»** нажмите **«Проверить все»** или отметьте отдельные подключения. Если есть изменения, приложение покажет их и предложит применить.

Проверка не переключает VPN. Для смены подключения есть отдельное действие **«Использовать это подключение»**.

## Что ещё доступно

- **Мониторинг:** графики скачивания и отдачи. Источник — сервер или роутер; сбор идёт только на открытой видимой странице.
- **Тест скорости:** iperf3 с роутера до AntiZapret, 10 потоков на 10 секунд. По умолчанию проверяется скачивание.
- **Доменное имя:** можно использовать домен сервера в VPN-конфигурациях.
- **Порядок карточек:** задаётся в «Доступах» и учитывается во всех разделах.
- **Резервная копия:** настройки можно скачать в зашифрованном виде и перенести на другую установку.
- **Конвертер:** ручная подготовка `.conf`, `routes.bat` и команды ASC прямо в браузере.

Пошаговые объяснения: [как пользоваться приложением](docs/usage.md).

## Что важно знать

Перед первым применением сохраните резервную копию настроек роутера. Новое подключение может потребовать отключения других VPN этого роутера — приложение покажет это в плане.

Для доступа к AWG Sync через интернет нужен пароль и защищённое соединение: HTTPS или SSH-туннель. Готовые способы приведены в инструкциях установки.

Файлы `config.yaml`, `.env` и резервные копии могут содержать пароли. Не выкладывайте их на GitHub и не прикладывайте к публичным сообщениям об ошибках.

```bash
npm ci
npm test
```

```text
node/       приложение, веб-интерфейс и тесты
docs/       инструкции
deploy/     шаблоны установки
scripts/    подготовка архива
```
